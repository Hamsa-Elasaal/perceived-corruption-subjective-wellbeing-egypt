# Data Source

This project uses data from **Wave 7 of the World Values Survey (WVS), Egypt (2018)**. The final report describes the cleaned analytical sample as 1,144 Egyptian respondents.

The original respondent-level dataset is intentionally not included in this repository. To access the source data, consult the official World Values Survey resources:

- [World Values Survey — official website](https://www.worldvaluessurvey.org/)
- [WVS Wave 7 documentation](https://www.worldvaluessurvey.org/WVSDocumentationWV7.jsp)

Please obtain the relevant Egypt Wave 7 data directly from WVS and follow the data access, citation, and redistribution conditions that apply to the dataset. This repository does not grant additional rights to redistribute the original survey data.
